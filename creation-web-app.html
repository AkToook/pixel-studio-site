Questions

Les questions qu'on nous pose.

Que comprend le prix de départ ?

Une première version avec les fonctions essentielles. Le prix final dépend du nombre d'écrans et de fonctions : on vous donne un devis fixe après le cadrage.

Combien de temps faut-il ?

En général quelques semaines pour une première version. Le planning précis est donné avec le devis.

Le code m'appartient ?

Oui. Vous recevez le code et les accès à la fin du projet, sans dépendance à notre agence.

Vous pouvez faire évoluer l'outil ensuite ?

Oui, avec un devis par évolution ou un forfait mensuel de maintenance.
