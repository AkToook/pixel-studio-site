Questions

Les questions qu'on nous pose.

Faut-il vraiment une application, ou un site suffit ?

Si vos clients reviennent souvent (commande, fidélité, réservation), l'application vaut le coup. Sinon, un site ou une web app coûte moins cher. On vous le dit honnêtement pendant le cadrage.

Que comprend le prix de départ ?

Une première version avec les fonctions essentielles. Le devis fixe est donné après le cadrage.

Apple peut refuser l'application ?

Apple vérifie chaque application. On prépare le dossier selon leurs règles et on gère les éventuelles corrections demandées.

Le code m'appartient ?

Oui, avec tous les accès à la fin du projet.
